# Desk run logs

One folder per desk (`<desk>/`, the mandate's file name without `.md`), one file per month (`<YYYY-MM>.md`), one line
per run that did something. Format, outcomes and rules: `docs/desks/README.md`, "Run log".

```
- 2026-10-22 08:41 · escalated · 1 pilot request waits on the founder (lead 42)
```

Append only. No email addresses, names of people or message text: this repository is public.
